Order confirmation emails → Trello

  1. In Trello, add a list on the 2 - Orders board called Order Confirmations.
  2. Board menu → Email-to-board settings: set the destination list to that list and copy the board's email address.
  3. In your Wilson & Bradley account, add that address as an additional order-confirmation email.
  4. Back here: Settings → Load lists → choose it above. New confirmations then appear on the Orders tab ready to match to an order.
